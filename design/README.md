# Design references

These files are the visual source of truth for implementation. They are not the website.

- `colors.json`, `typography.json`, `spacing.json`, `breakpoints.json` — tokens. Measured contrast is in `colors.json`.
- `tokens.md` — how to apply the tokens.
- `components.md` — visual rules that sit beside `docs/16-component-specifications.md`.
- `imagery-guidelines.md` — photography and the illustration-to-film path.
- `illustrations/` — original SVGs. The panicle, the contour field, and the small mark. They are not pictures of the farm.
- `mockups/` — static HTML compositions. Open them in a browser to see the intended homepage, the Raktshali page, and the mobile stacking. Do not copy this HTML into the Next.js app as the implementation. Rebuild it with the components in the docs.

No farm photograph is included, because none has been supplied.
